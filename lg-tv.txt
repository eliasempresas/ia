```bash

# Instalar dependências
cd projeto-app
npm install

# Empacotar
ares-package .

# Instalar na TV
ares-install --device TV_IP projeto.ipk

# Executar
ares-launch --device TV_IP com.suaempresa.aplicativo
```

PROJETO: LAUNCHER EE - Elias Empresas para LG TV
------------------------------------------------

CORES:
TEXTO=preto (#000000)
COR PRINCIPAL=#FF0000

VISÃO GERAL:
Aplicativo estilo "launcher/hub" exclusivo para LG webOS, centralizando 
todos os serviços Elias Empresas diretamente na TV. 

Além da interface, o aplicativo também executa em segundo plano rotinas de 
gerenciamento da TV (monitoramento, controle e identificação de recursos).

OBJETIVO:
- Ser a tela inicial alternativa da TV da família Elias.
- Centralizar gerenciamento invisível da TV e acesso ao ecossistema EE.
- Criar um ecossistema de aplicativos independentes mas integrados (superapp).
- Garantir atualizações automáticas sem depender da LG App Store.

------------------------------------------------
FUNCIONALIDADES DE GERENCIAMENTO (INTERNAS)
------------------------------------------------
- Monitoramento contínuo do sistema da TV (uso de CPU, RAM, rede).
- Identificação de dispositivos conectados (HDMI, USB, rede local).
- Controle automatizado de áudio, vídeo e rede em segundo plano.
- Alertas proativos (ex.: perda de conexão, dispositivo não identificado).
- Automação de tarefas internas sem interação do usuário.
- Logs de eventos armazenados e enviados para análise no servidor EE.

------------------------------------------------
MÓDULOS DO ECOSSISTEMA EE
------------------------------------------------
1. EE TV Manager
   - Interface para exibir status do monitoramento da TV.
   - Ajustes de entradas, vídeo, áudio, rede, etc... (tudo).
   - Perfis automáticos de uso (Cinema, Jogos, Música).

2. Mídia EE
   - Versão nativa do site midia.eliasempresas.com.
   - TV ao vivo, Filmes, Séries, Animes e player multimídia (HLS/DASH).
   - Plataforma para assistir o que quiser na TV.

3. Chat EE
   - Versão nativa do site chat.eliasempresas.com.
   - Comunicação em tempo real entre usuários e a inteligência artificial escolhida pelo usuário.

4. Câmeras EE
   - Visualização de câmeras da casa da Família Oliveira em streaming.eliasempresas.com/camera (futuro).
   - Integração com câmeras IP ou módulos internos Elias Empresas.

5. Painel Oliveira
   - Versão nativa do site portal.oliveira.eliasempresas.com.
   - Acesso a sistemas administrativos internos da Família Oliveira.
   - Exibição de dashboards e dados em tempo real.

6. IPTV EE
   - Versão nativa do site iptv.eliasempresas.com.
   - Player nativo de listas IPTV (compatível com M3U/M3U8).
   - Gerenciamento de playlists e canais favoritos.

7. Internet EE
   - Mostrar todos dados da internet em tempo real e também se o usuário escolher em um dia ou hora ou minuto.

8. Outros (em evolução)
   - Novos aplicativos EE podem ser plugados no Launcher conforme evolução.

------------------------------------------------
AUTENTICAÇÃO (SISTEMA DE CÓDIGOS)
------------------------------------------------
- Endpoint da API: https://api.eliasempresas.com/APIEE/familiaoliveiraEE/tv.php
- O aplicativo envia deviceId + função (create, authorize, approve).
- Ciclo completo:

1) CREATE
   - A TV solicita à API a criação de um código.
   - A API retorna um código único (6+ caracteres, expira em 5 minutos).
   - Status inicial: "pending".

2) APPROVE
   - Usuário ou servidor aprova o código manualmente ou remotamente.
   - Código muda de "pending" para "authorized".

3) AUTHORIZE
   - A TV verifica se o código já foi aprovado.
   - Quando status = "authorized", o dispositivo desbloqueia os módulos internos.

- Caso o código expire sem aprovação, é descartado automaticamente.
- Apenas 1 código "pending" por deviceId é mantido.
- Autorização é segura, baseada em X-API-KEY e persistida via tokens.

------------------------------------------------
TECNOLOGIA
------------------------------------------------
- Plataforma: LG webOS (HTML5, CSS3, JS/React com Enact Framework).
- Backend: APIs Elias Empresas já existentes.
- Atualizações: Modelo híbrido (App Shell + conteúdo dinâmico carregado do servidor).
- Hospedagem: Ubuntu Server (próprio servidor Elias Empresas).
- Segurança: Autenticação centralizada com API EE + códigos de autorização.

FUNCIONALIDADES PARA USO FAMILIAR

- Experiência simples e direta, mesmo com múltiplos módulos ativos.
